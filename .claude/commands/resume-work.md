# مهمة: استئناف العمل من `HANDOFF.md`

1. اقرأ الملف `HANDOFF.md` في جذر المشروع (`/Users/machhm/Desktop/cloud_skils/khazaabalat/HANDOFF.md`) بالكامل. إن لم يوجد، أبلغ المستخدم واقترح تشغيل `/handoff` أولًا.
2. اقرأ أيضًا `CLAUDE.md` (اختياري، للسياق) بشكل خفيف.
3. لخّص للمستخدم في **٥ أسطر بالضبط**، بالعربية، بهذا المعنى:
   - سطر ١: الهدف الحالي باختصار.
   - سطر ٢: آخر ما أُنجز (نقطة التوقّف) + تاريخ «آخر تحديث».
   - سطر ٣: الخطوة التالية المقترحة (الرقم ١ من «الخطوات المتبقية»).
   - سطر ٤: أي قرار مفتوح أو تحذير مهم (روابط placeholder، كود ميت، إلخ).
   - سطر ٥: أمر التحقّق/التشغيل السريع (`npm run build` بعد تفعيل nvm).

## قواعد
- **لا تبدأ أي تنفيذ أو تعديل بعد التلخيص.** انتظر تأكيد المستخدم صراحةً (مثل «ابدأ» / «تمام»).
- استخدم `Grep`/subagent إن احتجت تفاصيل إضافية — لا تُغرق السياق بقراءة ملفات كبيرة.
- بعد التأكيد فقط، ابدأ الخطوة التالية المذكورة (أو ما يحدّده المستخدم).
